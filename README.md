# SPECFEED GUI — 公開下載

此儲存庫提供 SPECFEED GUI 的安裝包、校驗檔與版本說明；程式碼於獨立的私有儲存庫維護。

- [最新版本](https://github.com/GSINVEST/specfeed-releases/releases/latest)
- [v0.5.2 下載與安裝說明](https://github.com/GSINVEST/specfeed-releases/releases/tag/v0.5.2)
- [一次性設定示範影片](https://youtu.be/VJjJPfts3vY)

請在 Release 頁的 Assets 下載 `SpecfeedGUI-*-windows-x64.zip`，完整解壓後執行 `Install.ps1` 或 `SpecfeedGUI.exe`。GitHub 自動產生的 Source code ZIP 僅包含本儲存庫說明，並非安裝包。
